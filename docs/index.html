Project Overview

Why this master plan matters

Ahmedabad is expanding rapidly. This project creates an integrated framework to assess existing sewerage and storm water systems, forecast future demand, identify weak points, and shape a phased roadmap up to 2057.

Technical Workflow

GIS database, modelling, forecasting, and planning

The workflow combines GIS database development, hydraulic and hydrologic modelling, population and runoff forecasting, master plan preparation, and implementation planning into one coordinated delivery sequence.
